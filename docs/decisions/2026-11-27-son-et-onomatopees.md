# 2026-11-27 · Son et onomatopées

## Décisions

1. **Origine du son** : le son vient de la synthèse ou de fichiers courts rendus avec Earshot et embarqués (mp3 ou m4a, lisibles sur iOS). Les scripts et sources sont suivis dans le dépôt. La licence de chaque source est vérifiée avant publication.
2. **Pas d'onomatopée à l'écran**, cris compris. Chaque coup se comprend par le son et la réaction de dégâts.

## Retrait dans le code

La règle 2 (pas d'onomatopée) est appliquée dans le code une fois le son et les réactions de dégâts intégrés, pour les Chapitres I et II. Le retrait est fait dans la même passe que l'intégration.
